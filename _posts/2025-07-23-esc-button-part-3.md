Since I also want to retrofit the [pedestrian warning system][1] (PWS), I also
want to have that button retrofitted. This button allows you to turn the system
on or off. I probably will not use it much, but I want it to have as original
as possible.

This means that I need the buttons with mode select, the speaker button and the
ESC/ASR button. This button does not exist, because the e-Golf never had the
ESC/ASR button. But these buttons are can be swapped, so I ordered two versions
and swapped the middle button. This will work, because the start-stop has the
LEDs installed, so it will light up when pressed.

Removing the buttons is easy. Use a plastic spudger on both sides of the button
to unclip the button from the frame, then pull the button out. The buttons I
used have part numbers `5GE 927 137 A` (e-Golf) and `5G1 927 137 P` (Golf).
